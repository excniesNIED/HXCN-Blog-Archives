# 版本对比评审：`index.*.md` / `index.en.*.md` 16 个变体

评审对象：本目录 9 个中文版 + 7 个英文版（其中 `index.en.k31p.md` 与 `index.en.o55.md` 字节完全相同，SHA-1 前缀 `a93ccc68`，按一份计分）。判据来自 `spec.md`（§一/§四 事实、§二 结构、§三 去 AI 味铁律、§五 写作决策）与 `AGENTS.md`。

## 0. 结论

- **中文首选 `index.o55.2.md`（8.45）**：唯一一个同时做到「像人写的」和「按 §五 决策落笔」的版本。它也是唯一写了 `7z e` + `dism /Mount-Image … /ReadOnly` + Node.js 逐字节补丁（§四）并给出 `2052 行 / 1974 行带时间戳`（§二 §四）、把 SID 截断成 `S-1-5-21-4291209427-…`（§五.2）、结尾只写「顺利进了系统」（§五.9）的版本。
- **英文首选 `index.en.4a.md`（7.52）**：唯一一个零 em-dash（§三.3 硬禁令）+ 三个坑全部第一人称认领（§三.2）+ 事实最完整的英文版。
- **最差两版：`index.38f.md`（3.58）与 `index.en.38f.md`（3.60）**。它们的毛病越过了「AI 味」这一档，直接编造事实：`天选游戏本`(L42)、`合上机箱盖`(L537，笔记本没有机箱盖)、`激动得直拍大腿`(L541)、事后给 C 盘「扩出 350 GB」(L598)，全部无证据且违反 §五.9。英文版另有 8 处禁用 em-dash 和 0.35/千词的缩写密度。
- **一个必须解决的问题**：`spec.md` §二 要求「中英文完全对齐」，而最佳中文版 `o55.2` **没有对应英文译本**（`index.en.o55.md` 是 `k31p` 的同源短版，不是 `o55.2`）。发布 `o55.2` 就必须按它重译一份英文；否则中英标题、章节数、事实块都对不上。
- **共性硬伤（8/9 中文、7/7 英文都中招）**：完整机器 SID、`C:\Users\admin`、LSA boot key `TC463EF4966D8796` 直接贴进正文，违反 §五.2；`BBI` 缩写展开，违反 §五.7；空间阶梯写成 `8.9 → 16.5`，漏掉 `16.0`，违反 §五.1。详见 §5。

## 5. 发布前必修（按优先级）

1. **隐私抹除（所有版本）**：把 `S-1-5-21-4291209427-303460211-4247354471` 统一写成 `S-1-5-21-4291209427-…`；删除 `Lsa boot key  TC463EF4966D8796` 输出行（`o55.2` 无此行，可直接抄它的写法）；`C:\Users\admin` → `C:\Users\<用户名>`，`admin / Admin` 账户列表同样匿名化。这是 §五.2 明令、且线上读者会照抄的字段。
2. **数字口径统一**：自带 InFlight 目录数按证据 `_fix/logs/inflight_mine.txt`（7335 行）写 **7335**，`4a`/`o55`/`o55.2`/`en.4a` 的 7334 都要改；空间阶梯写成 `100 多 MB → 8.9 GB（清桌面） → 16.0 GB（删 hiberfil 与更新残留） → 16.5 GB（删自己的 InFlight）`。
3. **删掉未经证实的细节**：`38f` 的机型/拍大腿/350 GB 扩容必须整段删；`1017` 的「六个小时」删掉；`4a`/`o55`/`k3`/`1017` 结尾停在「进了系统」。
4. **BBI 一律不展开**（§五.7），`38f`/`1017`/`v4p`/`en.*` 里那句 Boot Environment Infrastructure 是错的，尤其要删。
5. **`k3` 的 `copy` 记录**：正文说「从自己电脑拷一份顶上去」，代码块却是 `copy CorruptBak\SECURITY SECURITY`（把损坏件拷回去）。不改掉这一处，整个「假修复」章节逻辑不成立。
6. **`o55` 的字形与哈希**：`微软為了`(L320)、`厳格绑定`(L487) 换回简体；SHA-256 尾段 `…9a8f0b681a55fde67`(L693) 应为 `…9a8f06681a55fde67`。
7. **`v4p` 的两处欠债**：补上「PE 里 `reg load` 后没 `reg unload` → `0xd0000043`」这段自认的坑（L230 许诺了却没写），并把 `「」` 全部换成 `“”`。
